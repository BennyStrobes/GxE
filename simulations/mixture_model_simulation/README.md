# PA mixture model inference

`run_pa_mixture_model_inference.py` fits a two-component Bayesian mixture model to per-test eQTL summary statistics, computed separately in two environmental (E) bins, in order to distinguish tests exhibiting proportional amplification (PA: genotype effect scales with the bin-specific expression scale, beta_hat_b ~ N(eta * S_b, se_b^2)) from tests exhibiting a standard interaction (INT: beta_hat_b ~ N(beta + e_b * gamma, se_b^2)). Inference is via collapsed Gibbs sampling with hierarchical Gaussian priors on the per-test effects (eta, beta, gamma), inverse-gamma hyperpriors on their variances, and a Beta hyperprior on the mixture proportion pi (the fraction of PA tests).

## Input data

A tab-delimited file with a header row and one row per test:

| column | description |
|---|---|
| `test_idx` | test identifier |
| `S1`, `S2` | within-bin SD of expression in E bin 1 / bin 2 (potentially with genotype effect residualized out seperately in each bin) |
| `beta_1`, `beta_2` | within-bin OLS effect of (globally standardized) genotype on expression, estimated separately in each bin |
| `beta_1_se`, `beta_2_se` | standard errors of those effects |
| `e1_val`, `e2_val` | standardized E values of bin 1 / bin 2 (constant across tests) |

Notes:
- All quantities should be computed from within-bin regressions that include an intercept.
- Expression should be mean 0 per gene and scaled so that its residual variance from a global (across both bins) fit of `y ~ g + E + g*E` is 1. Scaling instead to total variance 1 makes each test's scale depend on its own genetic effect size, which biases the estimated PA fraction (in simulations: downward by ~0.02-0.05 with genotype-residualized S).
- Genotype should have mean 0 and variance 1 globally pefore createing summary stat
- `S1`/`S2` should be the standard deviation within bins. Potentially it should be the *genotype-residualized* within-bin SDs (the residual SD from the within-bin regression), not the raw within-bin expression SDs; raw SDs absorb bin-specific genetic variance and upwardly bias the estimated PA fraction.

Such a file is generated by `make_pa_mixture_model_input_from_data.py` (see below), for both simulated and real data.

## Generating input from data

`make_pa_mixture_model_input_from_data.py` takes the same inputs as `PA_h2.py` plus a list of variant-gene pairs to test, and writes the mixture model input files:

```bash
python make_pa_mixture_model_input_from_data.py \
    --expression-bed <expression_bed> \
    --plink2-per-chrom-stem <plink2_per_chrom_stem> \
    --binary-E-interaction-covariate-file <E_var_file> \
    --covariate-file <covariate_file or none> \
    --variant-gene-pairs-file <pairs_file> \
    --output-stem <output_stem>
```

- `--variant-gene-pairs-file`: tab-delimited with a header; the first two columns are gene id and variant id (one test per line). A tensorQTL `cis_qtl_top_assoc` file (filtered to significant genes) can be passed directly.
- If `--variant-gene-pairs-file` is `none` (default), pairs are identified with a cis interaction-QTL scan: for every autosomal gene, each cis variant (within `--cis-radius`, default 500kb of the TSS, as in `PA_h2.py`; MAF >= `--min-maf-per-bin`, default 0.05, in each E bin) is tested for the genotype x E term in `y ~ g + E + g*E + covariates`. The top variant per gene is kept, its p-value is Bonferroni corrected across the gene's cis variants, and genes with Benjamini-Hochberg q < `--interaction-fdr` (default 0.05) are used as pairs. All tested genes are written to `<output_stem>_interaction_qtl_top_per_gene.txt` (its first two columns can be reused as a pairs file). Note that pairs are selected and then estimated on the same samples.
- For each pair, covariates (if provided) are regressed out of expression and genotype across all samples, genotype is then standardized across all samples, expression is scaled to unit residual variance (see notes above), and per-bin statistics are computed (bin 1: E == 0, bin 2: E == 1).
- Outputs: `<output_stem>_pa_mixture_model_input.txt` (S = raw within-bin SD), `<output_stem>_pa_mixture_model_geno_resid_S_input.txt` (S = within-bin residual SD), and `<output_stem>_pa_mixture_model_test_key.txt` mapping `test_idx` to `gene_id` / `variant_id`.

The per-bin statistics are computed in `mixture_model_input_utils.py`.

## Simulation

`simulate_mixture_model_data.py` writes simulated data in the `PA_h2.py` input format (expression bed, plink2 genotype, binary E file) plus a variant-gene pairs file and an oracle file. `run_single_simulation.sh` then runs `make_pa_mixture_model_input_from_data.py` and inference on it, so simulated data passes through exactly the same input-generation code as real data. Requires the `PA-h2` conda environment (numpy, pgenlib).

## How to run

```bash
python run_pa_mixture_model_inference.py \
    --mixture-model-input-file <input_file> \
    --output-stem <output_stem>
```

Optional arguments (defaults in parentheses):
- `--seed` (1): random seed for the Gibbs sampler
- `--ig-a`, `--ig-b` (1e-5, 1e-5): shape/rate of the inverse-gamma hyperprior on the effect variances (weak/near-flat)
- `--pi-prior-alpha`, `--pi-prior-beta` (0.1, 0.1): Beta hyperprior on the mixture proportion pi

The sampler runs 5000 iterations with a 4000-iteration burn-in (set in the function defaults).

## Outputs

- `<output_stem>_global_parameter_posterior_summary.txt`: posterior mean and 95% credible interval for `pi`, `sig_sq_beta`, `sig_sq_gamma`, and `sig_sq_eta`.
- `<output_stem>_per_test_posterior_summary.txt`: per test, the posterior probability of being a PA test (`PA_posterior_prob`, Rao-Blackwellized average over post-burn-in sweeps) and the conditional posterior mean effects (`posterior_mean_eta` given PA; `posterior_mean_beta`, `posterior_mean_gamma` given INT).

`run_pa_mixture_model_inference_standard_gibbs.py` is an independent implementation of the same model using a standard (non-collapsed, all-univariate-updates) Gibbs sampler, with identical inputs and outputs; it serves as a correctness cross-check and mixes more slowly.
